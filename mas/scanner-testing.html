MAS scanner testing

Use this guide to configure a scanner, verify Settings, and test activation, deactivation, and status checks.

1. Configure the scanner

Factory setup QR

Scan once during app setup.

Steps

  1. Install the latest TrackVision app on the tablet.
  2. On the setup screen, scan the factory setup QR with the scanner.
  3. Confirm the factory, language, and time zone shown by the app.
  4. Complete setup without entering an admin code.
  5. Open Settings and confirm the scanner is connected.
This QR is for MAS testing only. It has no admin code, camera mode off, no zone, and no PIN.

2. Test scanner input

Use the existing PDF test-code sheets linked below. Do not use production labels during this test.

Test codes T1791644300 (PDF) Test codes T1791644319 (PDF)

Expected result

  • The scanner beeps and the app accepts the displayed code.
  • USB and HID scanner modes should both work.
  • Scanning with carriage return / line feed disabled should also work.

3. Activate and deactivate a code

  1. Select an available test order in the app.
  2. Activate one test code from a PDF.
  3. Confirm the app reports a successful activation.
  4. Deactivate the same test code.
  5. Confirm the app reports a successful deactivation.

4. Check code status

  1. Open the code status check in the app.
  2. Scan or enter the test code you just deactivated.
  3. Confirm the status is deactivated.
  4. Activate the code again and confirm its status updates to activated.

If any step fails, note the exact scanner mode, code, screen, and error message before contacting support.
